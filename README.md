# 💬 Slider i Dëshmive

Slider interaktiv i dëshmive të klientëve me foto profili dhe navigim. Butonat e radhës dhe të mëparshmes ndërrojnë dëshminë, dhe secila dëshmi shfaq foton e profilit, emrin dhe pozicionin e klientit.

## 🚀 Si ta hapësh

Hap `demo/index.html` në browser — kliko butonat `&lt;` dhe `&gt;` për të ndërruar dëshmitë. Çdo dëshmi ka foto profili, emër dhe profesion.
